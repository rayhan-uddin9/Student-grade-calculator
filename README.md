# Student Grade Calculator

A Python program that calculates a student's final grade based on marks from 5 subjects.

## What it does
- Takes marks for 5 subjects
- Calculates the average
- Shows the grade and pass or fail status

## How to run
python Student_Grade_Calculator.py

## Subjects covered
- Math, English, Science, Python, Database

## Built with
Python 3 — no extra libraries needed
