# 🎓 Student Grade Calculator

A Python-based academic result management system that calculates **GPA**, **CGPA**, and tracks student performance across multiple semesters.

---

## ✨ Features

- 📝 Enter marks for multiple subjects per semester
- 📊 Automatic **GPA** calculation per semester
- 🏆 **CGPA** calculation across all semesters
- 📈 Semester comparison — see if performance improved or dropped
- 💾 Saves all records permanently in a JSON file
- ✅ Input validation — no crash on wrong input
- 🎯 Academic standing — Excellent, Good, Average, Poor

---

## 🖥️ How to run

```bash
python Student_Grade_Calculator.py
```
